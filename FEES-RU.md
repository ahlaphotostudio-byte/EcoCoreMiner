# Как собирается комиссия

С 1.17.0: собственное нативное ядро EcoCoreMiner — **1,5%**, сторонние вычислительные движки под управлением EcoMine — **2% за сервис**. Расчёт идёт от подтверждённой выплаты пула после его удержаний; комиссии самого стороннего майнера учитываются отдельно.

## Что работает сейчас

1. Пул отправляет добытые монеты на указанный пользователем адрес.
2. Владелец сервиса проверяет выплату и создаёт сервисный счёт. Для ERG сервер дополнительно проверяет транзакцию и подтверждения в основной сети. Для остальных поддержанных монет основание выплаты проверяется владельцем вручную.
3. Сервер фиксирует ставку, основание и сумму комиссии. Повторный счёт за ту же выплату блокируется. Старые счета не пересчитываются по новой ставке.
4. Пользователь видит счёт и отдельно подтверждает оплату. Для ERG платёж проверяется в сети; для шлюза NOWPayments — по уведомлению и повторной проверке через API провайдера.
5. Получатель — настроенный и активированный владельцем адрес ERG либо платёжный аккаунт NOWPayments. Приложение не получает приватный ключ пользователя и не меняет его майнинговый кошелёк.

Пример для внешнего движка: с подтверждённых **100 ERG** сервисный счёт составляет **2 ERG**. После его оплаты остаётся **98 ERG**, без учёта сетевой комиссии платежа. Пример будущего нативного тарифа: **1,5 ERG** из **100 ERG**, остаток **98,5 ERG**.

Сохранённый в локальном калькуляторе адрес сам по себе не включает сбор. Владелец должен подключить и активировать получателя в разделе оплаты на сайте. Ни просмотр сайта, ни оценка дохода, ни тестовая сеть не создают оплату. Счета нативного движка пока не выставляются.

## Автоматическая комиссия

В версии 1.17.0 автоматическое удержание выключено. Для него нужен реальный канал выплат: интеграция пула/платёжного реестра с разделением суммы между пользователем и владельцем, сверкой и защитой от повторной выплаты. Расчёт 1,5%/2% подготовлен, но сам канал ещё не подключён.

Возможен другой механизм для собственного майнера — отдавать разработчику 1,5% активного времени вычислений (примерно 54 секунды за час). Это процент времени, а не гарантия ровно 1,5% полученных монет. В данном выпуске такой режим не реализован и не включён. Его нельзя одновременно тарифицировать повторным сервисным счётом.
