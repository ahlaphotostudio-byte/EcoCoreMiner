# Текущие комиссии: 2% / 3%

С 1.22.0 наш движок (EcoCoreMiner, EcoMine, EcoMine 3) — **2%**; сторонние движки через EcoMine — **3%** за сервис. Комиссии пула и самого стороннего майнера добавляются отдельно.

Сбор временем реализован только для одной ERG / Autolykos2 GPU-задачи. После 3528 учтённых секунд на адрес пользователя собственный движок работает 72 секунды на адрес комиссии. Для Rigel, lolMiner и SRBMiner: 3492 и 108 секунд. Учёт требует свежего положительного хешрейта; прогрев не учитывается. Неудачная попытка комиссии прекращается через 180 секунд без долга и возвращает исходные настройки.

Получатель: `9gbrsi2YX8qaCgedMBFmUA4dZZhKTjRAzXf4QwX2z9nTNJVZE7i`.
Пул: `stratum+ssl://erg.2miners.com:18888`.

Пул отдельно учитывает принятые решения и платит каждому адресу после своего порога. Это доля времени, а не точный процент монет. Из кошелька ничего не списывается. Комиссия в EcoMine включается после принятия условий в ERG-задаче. Самостоятельный пример JSON уже содержит опубликованные условия 2%; проверьте их до ручного запуска. В preview сбор можно отключить через `fee: null`; обязательная коммерческая лицензия не реализована.

Прежнее согласие с тарифом не повышается автоматически. Настройки пользователя сохраняются, сбор нужно подтвердить заново. Уже созданные счета и подготовленные выплаты не пересчитываются. Шлюз выплат и автосписание из уже полученных монет остаются выключены.

Для Bitcoin / ASIC и остальных монет сбор не подключён. Адрес ERG нельзя использовать для комиссии BTC. Реальное зачисление на пул и выплата комиссии этой сборкой ещё требуют аппаратной проверки.
