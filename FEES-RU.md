# Комиссии

В официальной поставке добыча требует коммерческой лицензии. Для ERG / Autolykos2 комиссия обязательна: собственные EcoMine / EcoMine 3 — 2% времени (72 секунды из 3600 учтённых секунд), поддерживаемые сторонние движки — 3% (108 секунд). Учитывается свежий положительный хешрейт; прогрев и простой исключаются. Комиссия пула и встроенная комиссия стороннего майнера добавляются отдельно.

Сбор выполняется переключением добычи на опубликованный адрес из [коммерческих условий](COMMERCIAL-LICENSE-RU.md). Из кошелька средства не списываются. При неудаче сбора майнер возвращается к пользователю без накопления долга. Подготовка и перезапуск влияют на реальный результат, поэтому доля времени не гарантирует точно такую же долю монет.

Для Bitcoin, ASIC и других монет лицензия обязательна, но автоматический сбор ещё не подключён. ERG-адрес для Bitcoin не применяется; эта редакция не создаёт денежного долга. Новый платный способ сбора потребует отдельного принятия новых условий. Функции Pro приобретаются отдельно; активация лицензии майнинга не оформляет подписку.

Прежние счета сохраняют исходные суммы. Условия новой версии пользователь принимает явно; расчёт предварительной оценки сам по себе не означает согласия.
