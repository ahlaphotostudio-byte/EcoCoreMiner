# Подключение ASIC

EcoCoreMiner 0.2.0 — подключение Bitcoin ASIC

EcoCoreMiner запускается на компьютере Windows/Linux x64 в одной локальной сети
с ASIC. На ASIC ничего не устанавливается и прошивка не меняется. Компьютер
передаёт задания пула и ответы устройства через Stratum v1. Вычисляет сам ASIC.
GPU на компьютере для этого режима не требуется. Один экземпляр шлюза обслуживает
один заданный IP ASIC. Поддержка конкретной модели подтверждается испытанием.

ПОДГОТОВКА
1. Нужен Bitcoin ASIC (SHA256d) с настройкой обычного Stratum v1 пула.
   ASIC для Scrypt, Kaspa и других алгоритмов к этому шлюзу не подключайте.
2. Подключите ASIC и компьютер к роутеру, предпочтительно кабелем Ethernet.
   В роутере закрепите их локальные IP. Пример: компьютер 192.168.1.10,
   ASIC 192.168.1.20. Это примеры — замените их своими адресами.
3. В кабинете выбранного Bitcoin-пула возьмите адрес сервера Stratum v1,
   порт и имя worker. Выплатной BTC-адрес настройте в кабинете этого пула.
   ERG-адрес для BTC не подходит. Seed-фраза и закрытые ключи не нужны.

НА КОМПЬЮТЕРЕ
4. Скачайте EcoMine369 1.23.0 с https://369apps.studio/ecocoreminer/ и распакуйте.
   Этот Windows-комплект уже содержит Python и ECOCORE.cmd.
   Для отдельной сборки EcoCoreMiner установите Python 3.10+ x64.
5. Откройте терминал в распакованной папке и выполните:
   ECOCORE.cmd account
   Откройте адрес portal из ответа. Войдите, проверьте код устройства, прочитайте
   условия, подтвердите их принятие и получите подписанную лицензию.
   Затем выполните: ECOCORE.cmd activate
   Вставьте лицензию по приглашению. Добыча от этого не запускается.
6. Скопируйте ecocore-asic-example.json в asic.json. Измените:
   pool — настоящий адрес Stratum v1 пула с его портом;
   worker — ваш worker по правилам пула, например account.worker1;
   password — пароль worker, часто x (уточните у пула);
   asic.listen — локальный IP компьютера;
   asic.port — 3333 либо другой свободный порт 1024–65535;
   asic.allowedPeer — локальный IP единственного ASIC.
   Поля algorithm: sha256d, backend: asic-sv1, fee: null оставьте как в образце.
   Поддерживается stratum+tcp:// либо stratum+ssl:// для соединения с пулом.
7. Проверьте файл: ECOCORE.cmd check --config asic.json
   Успешная проверка означает правильность конфигурации, не проверку оборудования.
8. При необходимости разрешите входящий TCP-порт 3333 в брандмауэре компьютера
   только для частной сети и IP вашего ASIC. Не открывайте этот порт в интернете
   и не настраивайте переадресацию WAN на роутере. Не отключайте весь брандмауэр.
9. Запустите: ECOCORE.cmd run --config asic.json
   Компьютер должен оставаться включённым, без сна и с доступом к интернету.
   На Linux команды аналогичны: python3 eco_core.py account / activate / run.

НА ASIC
10. Откройте локальный IP ASIC в браузере и войдите своим паролем устройства.
    Сохраните прежние настройки пула, чтобы можно было вернуться к ним.
11. Найдите раздел настройки пулов: Pool Settings / Miner Configuration
    (название зависит от модели и прошивки). Для первого пула укажите:
    URL: stratum+tcp://192.168.1.10:3333
    Worker: тот же worker, который задан в asic.json
    Password: тот же пароль worker
    Замените IP и порт на ваши. Здесь указывается КОМПЬЮТЕР, а не внешний пул.
    Нажмите Save / Apply по инструкции производителя.
12. Во время контролируемого испытания учитывайте резервные пулы ASIC: при
    потере шлюза он может переключиться на них и продолжить добычу напрямую.
    Для проверки остановки временно отключите резервные прямые пулы, сохранив
    их настройки. Остановка шлюза сама по себе не выключает питание ASIC.

ПРОВЕРКА
13. Проверьте соединение и хешрейт в статусе ASIC, затем accepted/rejected в
    журнале EcoCoreMiner и в кабинете внешнего пула. Хешрейт сам по себе не
    доказывает принятие решений. Убедитесь, что worker принадлежит вашему аккаунту.
14. Для остановки шлюза нажмите Ctrl+C. Проверьте поведение ASIC и его резервов.
    Охлаждение, питание, частоты и аварийную защиту контролирует прошивка ASIC;
    EcoCoreMiner не получает и не регулирует температуру ASIC через Stratum v1.

ЛИЦЕНЗИЯ И КОМИССИЯ
Лицензия устройства обязательна. Проверка — перед запуском и каждые 5 минут.
При отзыве или неуспешной проверке шлюз закрывает соединения. Подключение ASIC
к другим, отдельно настроенным пулам не контролируется лицензией EcoCoreMiner.
Автоматический сбор комиссии BTC пока не подключён и долг не начисляется.
Для ERG обязательны 2% на собственном движке / 3% на стороннем через EcoMine.
Полные условия находятся в COMMERCIAL-LICENSE-RU.txt.

ЕСЛИ НЕ ПОДКЛЮЧАЕТСЯ
Проверьте IP, порт, allowedPeer, частную сеть, работающий процесс шлюза и
брандмауэр. Ошибка unsupported method означает несовместимое расширение протокола:
сохраните журнал и модель/прошивку ASIC. Не меняйте прошивку наугад.
Для точных названий кнопок нужны модель ASIC и версия его прошивки.
Пример официальной инструкции настройки полей пула ANTMINER:
https://support.bitmain.com/hc/en-us/articles/360002287334-Connect-ANTMINER-S9-T9-S7-to-Antpool
