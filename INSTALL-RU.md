# EcoCoreMiner / установка

```text
EcoCoreMiner 0.1.0-preview · 19 октября 2026
Отдельный майнинговый движок EcoMine. Коммерческий релиз ещё не готов.

ЧТО ЕСТЬ
— Самостоятельный CLI без сайта, аккаунта и web-сервера.
— Собственный Autolykos2 / ERG: нативные EcoMine / EcoMine 3 модули NVIDIA.
— Собственный SHA256d / BTC: новый нативный модуль Windows / Linux x64,
  сборки для 14 CUDA-архитектур и Bitcoin Stratum v1.
— Экспериментальный шлюз Bitcoin Stratum v1 для одного ASIC в локальной сети.
— Реестр алгоритмов с честными статусами. Остальные ядра ещё не реализованы.
Видеокарта, конкретные ASIC, принятые пулом решения, скорость и потребление
этой версии не проверены на реальном оборудовании. CPU-проверка SHA256d
сравнена с известными блоками Bitcoin и независимым hashlib.

БЫСТРАЯ ПРОВЕРКА — БЕЗ МАЙНИНГА
Распакуйте весь архив. В отдельной поставке нужен Python 3.10+.
В комплекте EcoMine для Windows Python уже включён.
Windows, из папки программы:
  ECOCORE.cmd algorithms
  ECOCORE.cmd self-test --algorithm sha256d --cpu-only
Linux / Windows с установленным Python:
  python eco_core.py algorithms
  python eco_core.py self-test --algorithm sha256d --cpu-only
В Linux командой может быть python3. Самопроверка CPU не подключается к пулу.
Файлы native/*.so, *.dll, *.cubin проверяются по SHA-256 из манифестов.

ERG / NVIDIA
В отдельном ZIP сначала установите модули (загрузка около 19 МБ):
  ECOCORE.cmd setup --algorithm autolykos2
Linux: python3 eco_core.py setup --algorithm autolykos2
Программа проверяет архив и каждый модуль по SHA-256. Установка не запускает
майнинг. В полном EcoMine модули уже включены, повторная загрузка не нужна.
Если новая версия основного архива не совпадает с закреплёнными модулями,
обновите сам EcoCoreMiner; несовпадающий модуль установлен не будет.

1. Скопируйте ecocore-example.json в мой-профиль.json.
2. Замените worker на СВОЙ публичный адрес Ergo mainnet, при необходимости
   добавьте .worker. Никогда не указывайте seed-фразу или закрытый ключ.
3. Проверьте пул, номер видеокарты, maxTemperature и workloadPercent.
   Пул по умолчанию: stratum+ssl://erg.2miners.com:18888, пароль x.
4. ПРОВЕРЬТЕ КОМИССИЮ. В примере fee уже содержит условия 2% времени
   и accepted: true. Используйте этот профиль, только принимая эти условия.
   В preview fee: null отключает сбор; это не система обязательной лицензии.
5. Проверьте конфигурацию, затем отдельно запустите:
   ECOCORE.cmd check --config мой-профиль.json
   ECOCORE.cmd run --config мой-профиль.json
Для Linux замените ECOCORE.cmd на python3 eco_core.py. Ctrl+C останавливает
процессы. Потеря датчика NVIDIA и достижение предела температуры прекращают
работу. На запуске карта должна быть минимум на 10 °C холоднее предела.
workloadPercent — доля активной работы, не лимит ватт. Меньшая нагрузка может
снизить хешрейт. Эффективность подтверждается только измерением.

BITCOIN / NVIDIA — ЭКСПЕРИМЕНТАЛЬНО
Используйте schema: 1, algorithm: "sha256d", backend: "cuda",
experimental: true, pool и worker вашего Bitcoin-пула, fee: null.
Другие поля аналогичны ERG. Выполните check, затем run.
Практическая конкурентная добыча BTC требует ASIC. GPU-модуль здесь служит
базовой реализацией и проверкой вычислений, без обещания доходности.

BITCOIN / ASIC — ЭКСПЕРИМЕНТАЛЬНО
Скопируйте ecocore-asic-example.json. pool.example — заглушка: замените
официальным адресом вашего BTC-пула. Заполните worker/пароль по правилам пула.
asic.listen — локальный IPv4 компьютера со шлюзом; asic.allowedPeer — IP ASIC.
asic.port — свободный порт 1024..65535. Не выставляйте шлюз в интернет.
На ASIC укажите stratum+tcp://IP_КОМПЬЮТЕРА:ПОРТ. Шлюз использует worker
и пароль из конфигурации для авторизации и отправки решений.
Запустите check, затем run. Поддерживается один явно разрешённый IP.
Шлюз не прошивает ASIC, не меняет частоты, не читает его температуру и мощность.
Тепловая защита должна работать в самом ASIC. Проверка модели и реального
пула обязательна; Stratum v2 и индивидуальные API производителей не подключены.
Связь ASIC → шлюз внутри LAN без TLS; TLS к пулу — при stratum+ssl.

КОМИССИИ: НАШ ДВИЖОК 2%, СТОРОННИЕ ЧЕРЕЗ ECOMINE 3%
В этой версии сбор временем работает для ERG / Autolykos2.
EcoCoreMiner, EcoMine, EcoMine 3: 3528 секунд пользователю, затем 72 комиссии.
Rigel, lolMiner, SRBMiner через EcoMine: 3492 секунды пользователю, затем 108.
Считается только время со свежим положительным хешрейтом. Перезапуск и прогрев
не включены; неудачная попытка комиссии ограничена 180 секундами и не создаёт
долг. Затем восстанавливаются исходные пользовательские настройки.
Получатель комиссии (публичный ERG-адрес):
9gbrsi2YX8qaCgedMBFmUA4dZZhKTjRAzXf4QwX2z9nTNJVZE7i
Пул комиссии: stratum+ssl://erg.2miners.com:18888
Пул отдельно учитывает принятые решения и платит каждому адресу после порога.
Это доля времени, не точный процент монет. Из кошелька ничего не списывается.
Комиссии пула и самих сторонних майнеров добавляются отдельно.
Для BTC / ASIC нет адреса комиссии: сбор не подключён, поле fee должно быть null.
Согласие со старым тарифом не повышается автоматически: в EcoMine подтвердите
новые условия ERG-задачи. Автосписание уже полученных выплат не подключено.

ГРАНИЦЫ ПРОДУКТА
Вычислительные .cpp/.h/.cu и промежуточные PTX в архив не входят. Интерфейс
управления и протокольные адаптеры поставляются отдельно от закрытого ядра;
сохранены уведомления лицензий используемых компонентов. См. LICENSE.txt
и ECOMINE-NATIVE-NOTICES.txt. Коммерческие условия и обязательная лицензия
ещё не реализованы. Не называйте сборку поддерживающей все алгоритмы или ASIC.
В алгоритмах со статусом planned запуск завершается понятной ошибкой.
```
