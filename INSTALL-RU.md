# Установка и обновление

1. Скачайте `EcoMine369-1.21.0.zip` с https://369apps.studio/ecomine/ (старые версии сохранены в Releases) .
2. Сверьте SHA-256 с `release.json`. В Windows: `Get-FileHash .\EcoMine369-1.21.0.zip -Algorithm SHA256`.
3. Распакуйте архив в отдельную папку. В Windows запустите `START.cmd`; Python включён в архив. Для Linux нужен установленный Python 3: `sh start.sh`.
4. Создайте профиль: устройство, монета, движок, адрес пула и публичный адрес своего кошелька. Имя реально используемого майнера показывается до запуска.
5. Для ERG на NVIDIA выберите встроенный **EcoMine**. Сторонние майнеры устанавливаются отдельно. Проверьте профиль и запустите вручную. Остановить добычу можно кнопкой Stop.

Для существующей установки предпочтительнее встроенное обновление: оно сохраняет настройки, кошельки и историю. Закройте активный майнинг перед обновлением. Не переносите чужие настройки получателя комиссии.

Встроенный каталог GPU описывает совместимость, а не обещает измеренную скорость на каждой карте. Проверяйте доступную видеопамять, потребление, температуру и принятые пулом решения. Windows-подпись издателя у этой сборки не настроена.

## Состав

- EcoMine369 — настольное управление, мониторинг, профили, кошельки и обновления.
- EcoMine 0.2.0 — собственное вычислительное ядро ERG/NVIDIA с обязательным GPU self-test. EcoCoreMiner остаётся названием прежнего выбора управления компонентами.
- Сторонние майнеры устанавливаются отдельно под своими именами и лицензиями.
- Исходники CUDA/OpenCL, PTX и приватные материалы разработки не входят в скачиваемую программу.

Связка собственного EcoMine с пулом включена в 1.21.0 как выпуск для проверки на устройстве. Реальные скорость и принятые решения требуют аппаратного теста. См. [инструкцию нативного движка](NATIVE-RU.md).


EcoMine 3 (0.4.0) добавлен отдельно. В «Сравнение» есть подготовка трёх профилей; подробности в NATIVE-RU.md. Обновление не заменяет выбранный движок существующих задач.


## Настройка EcoMine 3

В «Монеты и задачи» выбери EcoMine 3. В блоке «Вычисления и энергия» доступны три режима, ручной предел нагрузки, температурная регулировка и подбор вычислительных блоков. Сначала сохрани задачу; добыча начинается только по кнопке запуска.

Для измерений открой «Сравнить на моём ПК», выбери эту задачу, включи «Найти подходящую нагрузку EcoMine 3» и цель. Подбор занимает до шести замеров с прогревом, ограничен временем и бюджетом. Для применения нужны принятые решения и измерения мощности/температуры. Режим «Баланс» оставляет варианты не ниже 90% лучшего измеренного хешрейта. Прирост менее 3% не принимается как доказанное улучшение. После замеров майнинг остановлен.

При замене видеокарты, драйвера или ядра повтори подбор либо выбери стандартный режим в задаче. Настройки со старой калибровкой не применяются к другой карте молча.
