# Установка и обновление

1. Скачайте `EcoMine369-1.17.0.zip` из Releases этого репозитория или с https://369apps.studio/ecomine/ .
2. Сверьте SHA-256 с `release.json`. В Windows: `Get-FileHash .\EcoMine369-1.17.0.zip -Algorithm SHA256`.
3. Распакуйте архив в отдельную папку. В Windows запустите `START.cmd`; Python включён в архив. Для Linux нужен установленный Python 3: `sh start.sh`.
4. Создайте профиль: устройство, монета, движок, адрес пула и публичный адрес своего кошелька. Имя реально используемого майнера показывается до запуска.
5. Установите выбранный сторонний майнер через приложение, проверьте профиль и запустите вручную. Остановить добычу можно кнопкой Stop.

Для существующей установки предпочтительнее встроенное обновление: оно сохраняет настройки, кошельки и историю. Закройте активный майнинг перед обновлением. Не переносите чужие настройки получателя комиссии.

Встроенный каталог GPU описывает совместимость, а не обещает измеренную скорость на каждой карте. Проверяйте доступную видеопамять, потребление, температуру и принятые пулом решения. Windows-подпись издателя у этой сборки не настроена.

## Состав

- EcoMine369 — настольное управление, мониторинг, профили, кошельки и обновления.
- EcoCoreMiner — новое название собственного ядра и интерфейса управления компонентами.
- Сторонние майнеры устанавливаются отдельно под своими именами и лицензиями.
- Исходники CUDA/OpenCL, PTX и приватные материалы разработки не входят в скачиваемую программу.

Самостоятельный нативный EcoCoreMiner с подключением к пулу будет отдельным выпуском после проверки. Он не подменяется сторонним майнером под новым именем.
