# Собственный вычислительный движок EcoMine

Клиент **1.19.0**: исходный **EcoMine 0.2.0** и отдельный **EcoMine 3 (0.3.0)** для сравнения на устройстве: **NVIDIA + ERG / Autolykos2**. Он содержит собственные вычисления, приём заданий пула и отправку решений. AMD/Intel и другие алгоритмы пока работают через отдельные движки.

## Запуск

1. Обновите EcoMine369 через раздел «Программа» или скачайте архив 1.19.0 с сайта.
2. В разделе «Движки» выберите NVIDIA, откройте «Собственное ядро EcoMine» и нажмите «Подготовить EcoMine · ERG».
3. Впишите совместимый ERG-пул и свой публичный ERG-адрес, проверьте номер GPU, мощность, тариф электричества и оценку дохода.
4. Сохраните профиль. Нажмите «Запустить», когда готовы к короткому наблюдаемому замеру.
5. Сначала пройдёт CPU/GPU self-test. Затем начнутся подготовка данных и вычисления. Проверяйте температуру, мощность и принятые пулом решения. Кнопка Stop завершает работу.

Без успешной проверки GPU и доступного датчика температуры запуск не допускается. Установка, обновление или создание профиля сами не запускают майнинг.

## Совместимость

Windows 10/11 x64; Linux x64 с Python 3.10+, glibc 2.34+ и libstdc++. Нужен драйвер NVIDIA, CUDA Toolkit не нужен. Подготовлены двоичные модули SM 52, 60, 61, 70, 72, 75, 80, 86, 87, 89, 90, 100, 103, 120. Модуль выбирается по архитектуре драйвера.

Поддерживается девятиполевой Ergo Stratum с десятичным target, 8-байтовым nonce и распределением extranonce. Адрес: `stratum+tcp://host:port` или `stratum+ssl://host:port`; TLS-сертификат проверяется. NiceHash и другие диалекты не заявлены совместимыми. Неизвестный формат останавливает запуск с сообщением.

При нехватке памяти ядро использует частичный кеш и досчитывает элементы на GPU. Это может значительно снизить скорость; особенно важен замер на RTX 4050 с 6 ГБ.

Отдельный self-test без пула:

```text
Windows: runtime\python.exe eco_mining.py --self-test --device 0
Linux:   python3 eco_mining.py --self-test --device 0
```

## Проверено и что осталось

Контрольный вектор совпадает с независимым эталоном. Пройдены тесты границ nonce, смены заданий, частичного кеша, переподключения, повторных ответов и повреждённых решений. Проверены также контракт нового исполнителя CUDA (на тестовом драйвере), выбор движка и прерывание экономичных пауз. Тестовый драйвер не выполняет GPU-вычисления.

Реальная видеокарта, запуск Windows DLL, хешрейт, энергопотребление и принятые решения внешнего пула в среде сборки не проверены. Self-test на устройстве подтверждает вычисления, но не заменяет замер на реальном пуле. Превосходство над другими майнерами не заявлено.

Тариф EcoMine — 1,5%; автоматическое удержание выключено. Вычислительный процесс не меняет кошелёк и не отправляет монеты. См. [порядок комиссии](FEES-RU.md).


## Сравнение EcoMine и EcoMine 3

1. Сохраните задачу NVIDIA · ERG с совместимым пулом, публичным кошельком и свежей оценкой дохода.
2. Откройте «Сравнение», выберите её исходной и нажмите «Подготовить сравнение EcoMine 3».
3. Создаются три новых профиля: исходный EcoMine, EcoMine 3 обычный и EcoMine 3 эко. Прежние задачи не изменяются. Добыча не начинается.
4. Оставьте лимит 0 на ноутбуке без регулировки мощности. Проверьте длительность и бюджет, затем нажмите «Начать замеры · майнинг».
5. После последовательных замеров все варианты остановятся. Сравните H/s на ватт, кВт·ч, температуру и решения; сохраните JSON/CSV. Повторите близкие результаты, меняя исходную задачу для другого порядка.

Эко-режим означает паузы между порциями GPU-работы, целевые 70% активного времени. Он не меняет напряжение или частоты и не означает 70% мощности. Хешрейт учитывает паузы. Экономия зависит от GPU, памяти, драйвера и нагрузки; возможна потеря скорости без выигрыша эффективности.

В EcoMine 3 изменён нативный исполнитель. Проверенные двоичные вычислительные модули Autolykos2 общие с EcoMine 0.2; исходный исполнитель сохранён отдельно. Перед каждым запуском обязательны те же проверки правильности вычислений.

Self-test только EcoMine 3: `python3 eco_mining.py --engine ecomine3 --self-test --device 0` (Windows: `runtime\python.exe` вместо `python3`).

Для рейтинга нужны измеренная мощность, температура, свежий хешрейт и принятые решения. Мощность всего ПК включает введённый расход остальных компонентов; сверяйте с ваттметром. При фиксированном ручном потреблении рейтинг экономии не подтверждается. Сырые количества shares при разной сложности пула напрямую несопоставимы.
