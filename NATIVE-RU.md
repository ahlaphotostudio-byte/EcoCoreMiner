# Собственные модули и границы проверки

EcoCoreMiner 0.1.0-preview отделён от сайта: CLI, JSON-конфигурация, реестр алгоритмов, проверка SHA-256 бинарных модулей и остановка по температуре для NVIDIA.

| Алгоритм | Реализация | Проверка |
|---|---|---|
| Autolykos2 / ERG | EcoMine 0.2.0 и EcoMine 3 0.4.0; NVIDIA | Перед запуском обязательная самопроверка GPU; реальный пул не проверен |
| SHA256d / BTC | Новые Windows DLL, Linux SO и 14 CUDA CUBIN; SV1 | CPU сравнен с genesis, вторым известным блоком и hashlib; GPU не проверен |
| Bitcoin ASIC | Ограниченный шлюз SV1 для одного IP в LAN | Локальный протокольный тест; ни одна модель ASIC не сертифицирована |
| Остальные алгоритмы | Модульный реестр | Собственные ядра ещё не реализованы |

Генезис Bitcoin и ненулевой prevhash проверяются отдельно. Сложность SV1 применяется к следующему notify. Защита от повторных и устаревших решений, ограниченные очереди, проверка CPU найденных GPU-решений. ASIC-шлюз не перепрошивает устройство и не управляет температурой или питанием ASIC; это функции его прошивки.

Самостоятельная сборка не содержит вычислительных .cu/.cpp/.h, PTX, исходников GPU или отладочной информации. В ней открыты протокольный адаптер и управляющий CLI; вычислительное ядро — бинарное. Результаты сторонних майнеров не считаются проверкой собственного ядра.
