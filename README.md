# EcoCoreMiner / EcoMine369

EcoCoreMiner **0.2.0** and EcoMine369 **1.23.0** require an activated commercial license for mining in the official builds.

- [Product and license](https://369apps.studio/ecocoreminer/)
- [Commercial terms](https://369apps.studio/ecocoreminer/license.html)
- [Activate a device](https://369apps.studio/products/account/?product=ecomine)
- [EcoMine369 Windows ZIP](https://369apps.studio/ecomine/EcoMine369-1.23.0.zip) — includes Python, desktop interface, CLI and CHECK-GPU.cmd.
- [EcoCoreMiner ZIP](https://369apps.studio/ecocoreminer/releases/EcoCoreMiner-0.2.0.zip) — Python 3.10+; Windows/Linux x64; ERG modules install separately from the checksum-verified official distribution.
- [Installation](INSTALL-RU.md), [ASIC setup](INSTALL-ASIC-RU.md), [fees](FEES-RU.md), [license](COMMERCIAL-LICENSE-RU.md), [validation limits](NATIVE-RU.md), [checksums](SHA256SUMS.txt).

The user must explicitly accept the current terms and activate the installation code. A signed license is checked online before starting and every five minutes. Failed renewal or revocation stops mining through the client. There is no automatic mining after activation. Offline self-tests remain available without a license.

ERG / Autolykos2 collection is mandatory at **2%** of counted mining time for EcoMine / EcoMine 3 and **3%** for supported external miners, in addition to pool and external miner fees. Bitcoin / SHA256d GPU mining and the one-device Stratum v1 ASIC gateway are available under the license. Automatic collection for Bitcoin and other coins is not connected; this edition creates no deferred payment debt for them.

This repository contains reviewed distribution documentation and update metadata. Computational sources remain private. The downloads are hosted on the product website; these files are not GitHub Release assets. Existing MIT and third-party rights remain applicable to their respective components.

Windows execution, GPU execution, actual ASIC compatibility, accepted shares on a real pool and energy measurements still need testing on the specific equipment. Algorithm availability does not establish hardware validation. Other native algorithms listed as planned are not implemented.
